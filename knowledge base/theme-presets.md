# Палитры оформления

В нативном интерфейсе режим `ui.theme` (`system`, `light` или `dark`) отдельно
определяет светлую или тёмную основу. Готовые палитры задают только акцентный
цвет через уже существующее `ui.primaryColor`; его общий путь применения
обновляет акцент в интерфейсе, редакторе, графе и диалогах.

Список палитр и их HEX-значения находятся в
`aquilum-app/native/src/ui/settings/schema.rs`.
Если сохранённый цвет совпадает с одним из вариантов без учёта регистра,
настройка показывает его имя. Для любого другого значения показывается `Custom`
(`Своя`); выбор этого пункта не меняет цвет. Ручной ввод остаётся доступным, а
выбор готовой палитры заменяет текущее значение ожидаемым акцентным цветом.

Палитры используют прежнее поле `ui.primaryColor`, поэтому настройки старых
версий сохраняются без миграции и продолжают отображать свой цвет как `Custom`.
