# Aquilum на Tauri (прежняя версия)

Прежняя версия Aquilum на Tauri v2, Preact и CodeMirror. Основное приложение теперь нативное, оно лежит в `../aquilum-app/`. Эта папка нужна, чтобы сверять возможности при переносе, и новых изменений не получает.

Общее ядро на Rust подключается из `../aquilum-app/core`.

```powershell
npm install
npm run tauri dev
```
